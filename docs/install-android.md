# Установка на Android

Этот комплект — кандидат, пока `release-manifest.json` имеет статус `blocked`.
Полная Android-регрессия и проверка на Pixel 9 Pro XL пока не завершены.
Фактические ограничения перечислены в `release-report.md` и
`device-acceptance.md`. Успешная сборка сама по себе не подтверждает готовность.

1. На компьютере проверьте комплект из каталога исходного проекта:
   `./scripts/toolchain.sh npm run verify:release -- /полный/путь/к/комплекту`.
   Код 0 означает прохождение всех проверок; 2 означает неполные/неверные
   материалы, 1 — внутреннюю ошибку или недоступный инструмент проверки.
2. Скопируйте `app-release.apk` и каталог `model/` на телефон по USB.
   Для модели сохраните оба файла рядом в Downloads:
   `Qwen3-1.7B-Q4_K_M.gguf` и `model-manifest.json`.
   Модель занимает 1 282 438 944 байта; для локальной установки нужны место
   под ещё одну копию и запас минимум 16 MiB. Дополнительные версии модели
   занимают дополнительное место.
3. Включите авиарежим, дополнительно отключите Wi-Fi. Через приложение
   «Файлы» откройте APK и разрешите этому приложению установку неизвестных
   приложений в системном диалоге Android. Установите «Немецкий словарь».
   Кандидат содержит ARM64, предназначен для Pixel 9 Pro XL; Android 7/API24
   — минимальная версия установки, проверка целевого телефона ещё требуется.
4. Откройте приложение и создайте профиль. Новый профиль должен иметь
   40 стартовых слов, нулевой прогресс и XP. WAV-записи этих слов уже в APK;
   каталог `audio/` содержит контрольные копии и описание записей.
5. Откройте **Локальная модель → Выбрать описание модели**, выберите
   `model-manifest.json`, затем **Выбрать файл GGUF** и выберите GGUF.
   Дождитесь окончания копирования и проверки. Не изменяйте описание модели.
   При отказе или ошибке проверьте свободное место и совпадение файлов;
   словарь и занятия остаются доступны.
6. Проверьте звук и четыре режима помощника: ассоциация, пример, текст,
   правило. Для собственных слов можно установить системный немецкий голос
   Android с офлайн-данными; доступность подтверждается в авиарежиме.
7. CSV и JSON выбираются через системный интерфейс файлов в разделе
   переноса данных. Формат CSV: UTF-8, запятая, заголовки `de,ru,pos,gender`;
   `de` без артикля, `pos=noun|adjective`, род существительного `m|f|n`.
   Перед импортом просмотрите ошибки и дубли. Полная JSON-копия включает
   профили, прогресс, занятия и награды; GGUF в неё не входит.

Для обновления сначала экспортируйте JSON-копию, затем установите новый APK
поверх существующего приложения с той же подписью. Не удаляйте приложение
перед обновлением: удаление очищает его локальное хранилище. Проверка сохранения
серий/XP и миграций после обновления включена в обязательную приёмку.

# Дополнительная практика с локальной моделью

**Основание:** пользователь согласовал добавление в план трёх функций: объяснение ошибки, предложения с пропусками и практика трудных слов. Документ определяет их первый объём; реализация ещё не начата.

**Цель:** после ошибки понять её причину и закрепить слова личного словаря в коротких предложениях без интернета. React Native, SQLite, локальная модель и отдельные профили сохраняются.

## 1. Объяснение ошибки

После принятой неверной попытки показывать кнопку «Объяснить ошибку». Экран содержит задание, «Ваш ответ», правильный ответ из сохранённого Question.expected и короткое объяснение на русском. Модель получает фактический ответ, тип задания, карточку и применимый фрагмент справочника. Для перевода, письма и аудирования можно пояснить разницу и дать простой пример; правила рода и артикля объясняются по справочнику. Вопросы за пределами справочника не получают выдуманного объяснения правила.

Сохранять `submittedAnswer?: string` в JSON результата принятой попытки и сессии. Старые результаты без этого поля остаются читаемыми: показывать «Ответ не сохранён» и разбирать правильный вариант без предположений о том, что ввёл пользователь. Повторный submit возвращает первоначальный ответ и результат. Возврат из помощника сохраняет attemptId, результат и слово. Объяснение не может пересмотреть правильность попытки.

## 2. Предложения с пропусками

Из карточки — действие «Практика с пропуском». Для первой версии скрывается одно немецкое слово в простой фразе уровня A1; отдельные пропуски артиклей и изменение формы слова не входят в этот объём. Модель создаёт контекст и перевод; целевое слово и эталон берутся из выбранной карточки приложением. Перевод можно открыть по запросу, при этом показывается «Подсказка открыта».

Пользователь вводит слово, получает правильность, полную фразу и перевод. Проверка использует существующую normalizeAnswer/checkAnswer: NFC, регистр и пробелы нормализуются, ä/ö/ü/ß сохраняются. Модель не оценивает ответ. После ответа можно перейти дальше или повторить упражнение; повторная отправка заблокирована.

Ответ модели проходит проверку структуры, длины, принадлежности слова профилю и актуальности редакции. Не показывать частично сгенерированный JSON как готовое упражнение. Некорректный результат даёт сообщение «Не удалось создать упражнение» и кнопку повторной генерации без автоматического цикла запросов. Структурная проверка не гарантирует грамматику: качество требует отдельной приёмки реальной модели.

## 3. Практика трудных слов

На существующем экране «Трудные слова» добавить отдельную кнопку «Практика с помощником». До пяти слов выбираются приложением из текущего `word_progress.difficult=1`, в существующем порядке `de,id`. Пользователь видит выбранные слова до запуска. Каждому слову соответствует одно предложение с пропуском из функции 2. Итог показывает количество правильных ответов и ошибок только этой практики.

Если трудных слов нет, объяснить это и предложить открыть словарь. Изученное трудное слово с будущей датой повторения допускается в дополнительной практике: она не меняет дату. Существующие «Изучать трудные слова» и «Повторить трудные слова» сохраняют свои правила и продолжают начислять XP в обычном занятии.

## Общие правила

- На экране дополнительной практики явно показывать «Практика без XP и изменения серии». Она не меняет mastery, streak, difficult, recoveryCorrect, recoveryErrors, dueDay, daily goal или ежедневную серию посещений.
- Основные правила неизменны: 20 правильных подряд; ошибка до освоения сбрасывает серию; повторения через 1, 3, 7, 14, 30, 60 дней; ошибка повторения назначает завтра; 3 ошибки делают слово трудным, 3 правильных подряд в обычном обучении снимают этот статус; +10 XP за правильный ответ, +50 за первое освоение, уровень каждые 500 XP.
- Упражнения и их локальные счётчики живут только на время экрана практики. После выхода или force-stop они сбрасываются; сохранённый основной прогресс остаётся в SQLite. Новые упражнения и объяснения не сохраняются в `aids` в первой версии.
- Существующие четыре функции помощника и сохранённые подсказки остаются совместимыми. Поле submittedAnswer включается в резервную копию через существующий result JSON, без новой таблицы или смены BackupV1. Импорт старых BackupV1 обязателен.
- Одна генерация одновременно для старых и новых функций; общие отмена, освобождение runtime и защита от смены профиля/редакции слова. При смене профиля очищаются также текст ответа, объяснение, упражнение и счётчики практики.
- Без файла модели показывать установку и доступ к обычному обучению. Не выполнять сетевых запросов. Не добавлять модель в стартовый путь приложения.
- Правильный ответ и результат попытки выводятся приложением независимо от текста модели. Генерация может предлагать объяснение, но не изменять словарь, XP, расписание или результат проверки.
- Приёмка: TDD для новых сценариев, полная регрессия release APK в Android-эмуляторе с реальной моделью, отдельная оценка новых 30 языковых случаев. Скорость и память на физическом Pixel 9 Pro XL остаются отдельной проверкой.

## 2.9. Sein с профессиями

Профессии: Lehrer — учитель; Programmierer — программист; Designer — дизайнер; Manager — менеджер; Sportler — спортсмен; Arbeiter — рабочий.

Для каждой профессии тренируются семь сочетаний:

| Лицо | Сочетание на примере Programmierer |
| --- | --- |
| я | Ich bin Programmierer. |
| ты | Du bist Programmierer. |
| он | Er ist Programmierer. |
| мы | Wir sind Programmierer. |
| вы, группа на «ты» | Ihr seid Programmierer. |
| они | Sie sind Programmierer. |
| Вы, вежливое обращение | Sie sind Programmierer. |

Всего 6 × 7 = 42 сочетания. Словарный артикль этих профессий — der; после sein при простом назывании профессии артикль опускается. Формы множественного числа перечисленных профессий совпадают с единственным. Это правило о данных шести словах, а не обо всех названиях профессий.
